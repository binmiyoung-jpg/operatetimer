1
Google Cloud Console에서 프로젝트 생성
console.cloud.google.com 접속 → 새 프로젝트 생성
왼쪽 메뉴 → API 및 서비스 → 라이브러리 → Google Drive API 사용 설정
2
OAuth 클라이언트 ID 생성
사용자 인증 정보 → OAuth 클라이언트 ID
애플리케이션 유형: 웹 애플리케이션
3
Client ID 입력
생성된 클라이언트 ID를 아래에 붙여넣고 저장하세요.
